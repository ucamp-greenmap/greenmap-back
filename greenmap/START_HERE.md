# 📋 GCP VM 배포 - 시작하기 전에 읽어보세요!

## 🎯 목표

Spring Boot 애플리케이션을 GCP VM(Compute Engine)에 배포하여:

-   ✅ 단일 인스턴스로 파일 시스템 공유 문제 해결
-   ✅ 세션 관리 문제 해결
-   ✅ 안정적인 서비스 운영

---

### 1️⃣ 빠른 시작 (추천)

**파일**: `QUICK_START_VM.md`

-   핵심 내용만 간단히 정리
-   복사-붙여넣기로 빠르게 진행
-   **소요 시간**: 약 30-40분

### 2️⃣ 상세 가이드

**파일**: `GCP_VM_DEPLOYMENT_GUIDE.md`

-   dev 브랜치에 푸시하면 자동 배포

## 🚀 시작 순서 (권장)

### Step 1: 준비 (5분)

1. GCP 계정 로그인
2. 신용카드 등록 ($300 무료 크레딧 받기)

1. 서비스 계정 권한 추가
2. GitHub Secrets 확인
3. 자동 배포 테스트

## 🔍 Cloud Run vs VM 비교

### Cloud Run의 문제 (현재)

-   ❌ 인스턴스가 여러 개 뜨면 파일 공유 안 됨
-   ❌ 세션이 인스턴스마다 분리됨
-   ❌ 로컬 캐시 동기화 안 됨
-   ✅ 자동 스케일링
-   ✅ 저렴한 비용 (~$10/월)

### VM의 장점 (전환 후)

-   ✅ 단일 인스턴스로 파일 공유
-   ✅ 세션 관리 간단
-   ✅ 로컬 캐시 동기화 자동
-   ✅ 더 많은 제어권
-   ❌ 수동 관리 필요
-   ❌ 약간 높은 비용 (~$30/월)

## 🆘 문제 발생 시 어디를 봐야 할까?

### 1. VM 생성이 안 돼요

→ `GCP_VM_DEPLOYMENT_GUIDE.md` Step 1-2 참고

### 2. Docker 설치가 안 돼요

→ `QUICK_START_VM.md` 섹션 2 참고

### 3. 애플리케이션이 안 떠요

→ `GCP_VM_DEPLOYMENT_GUIDE.md` 문제 해결 섹션

### 4. DB 연결이 안 돼요

→ Cloud SQL Private IP 확인
→ VM과 Cloud SQL이 같은 VPC인지 확인

### 5. 외부에서 접속이 안 돼요

→ 방화벽 규칙 확인
→ VM 외부 IP 확인
→ 컨테이너 실행 상태 확인 (`docker ps`)

## 📞 도움이 필요할 때

### 로그 확인하기

```bash
# 애플리케이션 로그
docker logs -f greenmap

# Nginx 로그 (있는 경우)
sudo tail -f /var/log/nginx/error.log

# 시스템 로그
sudo journalctl -xe
```

### 상태 확인하기

```bash
# Docker 컨테이너
docker ps

# 시스템 리소스
htop

# 포트 확인
sudo netstat -tlnp | grep 8080
```
